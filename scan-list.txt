# Список имён для netprobe scan
# Запуск:  python3 netprobe.py scan --list scan-list.txt --json scan.json
#
# Формат: имя, через пробел или запятую подпись.
#   ## начинает новую группу
#   #  комментарий
#
# Проверяется реакция DPI на ИМЯ в ClientHello — сами сайты не трогаются,
# все запросы идут на один и тот же узел. Поэтому список можно расширять
# свободно, но помни: каждое имя — до 4 секунд при таймауте.
#
# Контрольную группу НЕ УДАЛЯЙ. Без неё сплошной провал не отличить
# от обрыва связи.
